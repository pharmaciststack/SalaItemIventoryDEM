## ใหม่ใน v2.2.0 — สวยขึ้น เร็วขึ้น

- **ดีไซน์ใหม่ทั้งระบบ**: หัวเว็บสีเขียวไล่เฉด, การ์ดมุมโค้ง, ไอคอนแทนอีโมจิ, วงแหวนความคืบหน้าในหน้าเช็คสต็อก,
  โครงร่างขณะโหลด (skeleton), รหัสอุปกรณ์แสดงแยกส่วน หมวด · สาขา · วันที่ · เครื่องที่
- **หน้าลงทะเบียนแสดงรายการอุปกรณ์รุ่นเดียวกัน**: พิมพ์ชื่อรุ่นแล้วเห็นทันทีว่ามีกี่เครื่อง อยู่สาขาไหน เครื่องที่เท่าไร
  (เครื่องในสาขาที่เลือกจะถูกไฮไลต์ และแจ้งเตือนถ้าชื่อรุ่นเดียวกันสะกดหลายแบบ)
- **เร็วขึ้น**
  - ไม่ต้องโหลดตัวคอมไพล์ Tailwind และไลบรารีไอคอนทั้งชุดในเบราว์เซอร์อีกต่อไป (หน้าเว็บพร้อมใช้จาก ~3.3 วินาที → ~0.1 วินาที บนเครื่องทดสอบ)
  - เปิดแอปครั้งถัดไปแสดงข้อมูลจากแคชในเครื่องทันที แล้วซิงก์ข้อมูลล่าสุดเบื้องหลัง
  - เข้าสู่ระบบ/เปิดแอปเรียกเซิร์ฟเวอร์ครั้งเดียว (เดิม 2 ครั้ง) · โหลด Google Sign-In เฉพาะตอนต้องล็อกอิน
  - กด "ปกติ" / บันทึกผลตรวจ แสดงผลทันทีไม่ต้องรอเซิร์ฟเวอร์ (ถ้าบันทึกไม่สำเร็จจะย้อนกลับและแจ้งเตือน)
  - Backend อ่านเฉพาะแถวท้ายของชีต History และอ่านหัวตารางครั้งเดียวต่อคำขอ

### Build (หลังแก้ `index.html` / `app.js` / `src/styles.css`)

```bash
npm install
npm run build
```

build จะ: รวมไอคอน Lucide เฉพาะที่ใช้ · สร้าง `app.css` · ใส่ `?v=<hash>` ท้ายไฟล์ และเปลี่ยนชื่อแคชใน `sw.js`
เพื่อให้ผู้ใช้ได้ไฟล์ใหม่ทันที — **ต้อง commit ไฟล์ที่ build แล้วด้วย** (`app.css`, `index.html`, `sw.js`)
ถ้าแก้แค่ `config.js` ก็ควรรัน build เพื่ออัปเดตเลขเวอร์ชันไฟล์

## ฟีเจอร์ใน v2.1.0

- **Multiplatform (PWA)**: ติดตั้งเป็นแอปบน Android / iPhone / iPad / Windows / Mac ได้จากเบราว์เซอร์
  มือถือมีแถบเมนูด้านล่าง ใช้งานมือเดียวได้
  - Android / Chrome / Edge: กดปุ่ม **"ติดตั้งแอป"** มุมขวาบน (หรือเมนู ⋮ → ติดตั้งแอป)
  - iPhone / iPad: Safari → ปุ่มแชร์ → **"เพิ่มไปยังหน้าจอโฮม"**
- **ผูกสาขากับผู้ใช้**: พนักงานเห็น/แก้ไข/ลงทะเบียน/ตรวจนับได้ **เฉพาะสาขาที่ลงทะเบียนไว้ในชีต Users** เท่านั้น
  (บังคับที่เซิร์ฟเวอร์ — เรียก API ข้ามสาขาจะถูกปฏิเสธ) · แอดมินเห็นทุกสาขา
- **คอนโซลเช็คสต็อกสาขา**: รอบตรวจนับรายเดือน, แถบความคืบหน้า, กด "ปกติ" ได้ทันที หรือบันทึก ชำรุด / ไม่พบ (ต้องมีหมายเหตุ),
  **สแกน QR ต่อเนื่อง** ทีละเครื่อง, พิมพ์ใบตรวจนับประจำเดือน (A4 พร้อมช่องลงชื่อ)
- **รายงานจำหน่าย**: วิธีการจำหน่าย, วันที่, **ผู้จำหน่ายสินค้าออก**, หมายเหตุ/เหตุผล และ **รูปถ่าย 1–3 รูป (บังคับ)**
  → ออกเลขที่รายงาน `DSP-ปปดด-XXXX` + เปลี่ยนสถานะเป็น "จำหน่ายแล้ว" อัตโนมัติ + พิมพ์รายงาน A4 พร้อมช่องลงชื่อ 3 ฝ่าย
  แอดมินยกเลิกรายงานได้ (สถานะอุปกรณ์กลับเป็นเหมือนเดิม)
- **แดชบอร์ด**: ความคืบหน้าตรวจนับเดือนนี้รายสาขา — คลิกเพื่อเปิดคอนโซลของสาขานั้น

## ขั้นตอน Deploy

### 1. ตั้งค่า Google Sign-In (ครั้งเดียว)
Google Cloud Console → APIs & Services → Credentials → OAuth Client ID ของระบบแจ้งซ่อม
(`854838901494-cuhm...`) → **Authorized JavaScript origins** เพิ่ม:
- `https://pharmaciststack.github.io`
- `http://localhost:3000` (น่าจะมีอยู่แล้วจากระบบแจ้งซ่อม)

### 2. ทดสอบบน Sheet สำเนาก่อน
1. เปิด Google Sheet ข้อมูลอุปกรณ์ → File → **Make a copy**
2. ในสำเนา: Extensions → Apps Script → ลบโค้ดเดิม วาง `apps-script/Code.gs` ทั้งไฟล์
3. ตั้ง `AUTH_SHEET_ID` = ID ของ Google Sheet ระบบแจ้งซ่อม (จาก URL `.../spreadsheets/d/<ID>/edit`)
   บัญชีที่ Deploy ต้องมีสิทธิ์แก้ไข Sheet ระบบแจ้งซ่อมด้วย
4. Deploy → **New deployment** → Web app → Execute as: **Me** · Who has access: **Anyone** → อนุญาตสิทธิ์
   (v2.1 ขอสิทธิ์ **Google Drive** เพิ่ม สำหรับเก็บรูปรายงานจำหน่าย)
5. คัดลอก URL มาใส่ `APPS_SCRIPT_URL` ใน `config.js` แล้วรัน `npm run build` และทดสอบที่ http://localhost:3000
   (เปิด URL ของ Apps Script ตรงๆ ต้องเห็น `"version":"2.0.0"`)

### 3. ขึ้นระบบจริง
1. Sheet จริง → Apps Script → วาง `Code.gs` ใหม่ (ตั้ง `AUTH_SHEET_ID` เหมือนเดิม)
2. Deploy → **New deployment** (อย่าแก้ deployment เดิม — หน้าเว็บเก่าจะยังใช้งานได้จนกว่าจะ push)
3. ใส่ URL ใหม่ใน `APPS_SCRIPT_URL` (ไฟล์ `config.js`) → `npm run build` → commit → push → GitHub Pages อัปเดตภายใน 1–2 นาที
4. ครั้งแรกที่มีการเรียกใช้ ระบบจะเพิ่มคอลัมน์ `Status, UpdatedAt, UpdatedBy, CreatedBy,` ต่อท้าย `Sheet1`
   `LastCheckAt, LastCheckBy, LastCheckResult, DisposalID` และสร้างชีต `History`, `Disposals` ให้อัตโนมัติ — **ไม่แก้ไขคอลัมน์เดิม**
5. เมื่อใช้งานได้แล้ว: Deploy → Manage deployments → **Archive deployment เก่า**
   (deployment เก่าไม่มีระบบ login ใครรู้ URL ก็อ่าน/เขียนข้อมูลได้)

### ย้อนกลับ (Rollback)
คืนค่า `index.html` เป็นเวอร์ชันเดิม (`git revert`) — ตราบใดที่ยังไม่ Archive deployment เก่า หน้าเว็บเก่าจะทำงานได้ทันที

## ข้อควรรู้
- ห้ามเปลี่ยนชื่อชีต `Sheet1` และชื่อหัวคอลัมน์เดิม (ระบบอ้างอิงคอลัมน์จากชื่อหัวตาราง)
- ข้อความที่บันทึกผ่านระบบจะมี `'` นำหน้าใน Sheet เพื่อกันไม่ให้ Sheets แปลงเป็นสูตร/วันที่
- การลบรายการจะเก็บข้อมูลเดิมทั้งแถวไว้ในชีต `History` (คอลัมน์ From) เผื่อกู้คืน
- เข้าสู่ระบบแต่ละครั้งใช้ได้ 6 ชั่วโมง
- สติกเกอร์: ตั้งค่าเครื่องพิมพ์ Scale = 100% / Actual size
- รอบตรวจนับ = เดือนปฏิทิน (เครื่องที่ตรวจตั้งแต่วันที่ 1 ของเดือนนับว่า "ตรวจแล้ว") ประวัติการตรวจทุกครั้งอยู่ในชีต `History` (Action = check)
- รูปรายงานจำหน่ายถูกย่อเหลือด้านยาว 1280px ก่อนอัปโหลด และแชร์แบบ "ทุกคนที่มีลิงก์ดูได้" เพื่อแสดงในแอป
  (ถ้า Google Workspace ขององค์กรไม่อนุญาตการแชร์แบบนี้ รูปจะแสดงเฉพาะคนที่มีสิทธิ์ในโฟลเดอร์)
- แอปที่ติดตั้งแล้วจะอัปเดตเองเมื่อเปิดขณะมีอินเทอร์เน็ต (Service Worker ใช้ไฟล์ล่าสุดจากเน็ตก่อนเสมอ)
